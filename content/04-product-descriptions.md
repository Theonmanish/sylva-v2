**Sources checked:** Brand Profile v1.0, Tone of Voice Guide v1.0, Website Structure Blueprint, PRD v1.0, Project Instructions

**What this document is.** No product catalogue has been confirmed, so this file does not contain descriptions of individual pieces. It contains the system for writing them: terminology, a product data sheet, description templates, reusable material wording, customisation information and the product-detail page structure. Once the business confirms a piece's details, its description is assembled from these parts and checked against the data sheet.

**How to read this file**

- **[WEBSITE COPY]** blocks are publishable once approved. Where a block applies only to some pieces, its condition is stated.
- **[TEMPLATE]** blocks are structures for writing per-piece copy. They contain variables in curly brackets, for example {vessel_form}. They are never published as written.
- **[INTERNAL]** blocks are guidance and must never appear on the website.
- **[REQUIRES CONFIRMATION]** marks anything that must be verified before publishing.
- Reusable copy blocks have IDs (for example, B-VESSEL) so other documents and the build can refer to them.

## 1. Rules for every product description [INTERNAL]

1. **Facts first.** Every statement comes from the product data sheet (section 3). If a field is empty, the sentence is left out. Nothing is estimated or filled in from the working lists in the brand profile.
2. **Write from the object outward.** Name the element, say what it contributes, then, if useful, describe what a viewer may notice. This follows the tone guide.
3. **Only what is present.** Name a plant, moss, wood, stone or substrate only if it is actually in that piece.
4. **Length.** Product description: 2 to 4 sentences. Character line: 20 words or fewer. Not every piece needs an atmospheric sentence.
5. **No praise without detail.** Replace "stunning", "beautiful", "exquisite" and similar with a specific observation. If there is no specific observation, say nothing.
6. **No care promises.** No "maintenance-free", "self-sustaining", "thrives" or lifespan wording. Use the standard care line (block B-CARE) or product-specific guidance from document 08.
7. **No commercial language.** No "Buy now", "In stock", "Limited", "Bestseller", "New". The route is an enquiry.
8. **Terrariums and kokedama stay separate.** Kokedama descriptions never use *vessel*, *glass*, *hardscape* or *landscape*.
9. **Real photography.** Images and alt text describe the actual piece.
10. **Check before publishing.** Use the checklist in section 11.

## 2. Product terminology [INTERNAL]

This extends the terminology table in document 01 with terms specific to products. All files use these terms.

| Use | Meaning | Avoid |
|---|---|---|
| Piece | A single ready-made terrarium or kokedama. Used in all customer-facing product copy | Item, product, SKU, unit |
| Ready-made | A piece already composed | In stock, available now |
| Format | The vessel type of a terrarium (see section 4) | Using it as a synonym for size |
| Size category | A size band, differentiated mainly by vessel size (see section 4) | Using it as a synonym for format |
| Vessel form | A plain description of the glass shape, for example "a glass jar" | Container, pot |
| Character line | The one-sentence summary of a piece | Tagline, USP, hook |
| Composition | The finished arrangement | Design piece, masterpiece |
| Hardscape | Natural structural elements (roots, wood, stone). Define on first use | Using it without explanation |
| Substrate | The growing medium. Define on first use | Using it without explanation |
| Custom composition | A piece developed through an enquiry | Bespoke, one-of-a-kind |

**Plant naming convention.**

- Use the botanical name where confirmed. Add a common name only if the business confirms it.
- Write the genus and species in italics on first mention, for example *Fittonia albivenis*. After that, the genus name alone is acceptable.
- Never present a common name as a botanical name.
- British and Indian English spelling: colour, customise, enquiry.

**Product names.** Names are chosen by the business and are not invented here. Recommended approach: short, plain, descriptive, with no superlatives or promotional adjectives. Names are confirmed together with the catalogue. [REQUIRES CONFIRMATION]

### 4.3 The conflict to resolve

*Micro* appears in both lists. It is unclear whether it means a vessel format or the smallest size. Until the catalogue structure is finalised:

- Keep format and size category in separate fields.
- Do not publish a combined label such as "Micro Jar" unless the business confirms it.
- Describe formats only when confirmed, and describe size only as "differentiated by vessel size".

### 4.4 Publishable format and size copy

**[WEBSITE COPY]** Block B-SIZE. Publish only the sentence that applies.

> Sizes are differentiated by vessel size.

**Rule.** Do not invent measurements, volumes or plant counts. If dimensions are not confirmed, omit the size line and the "Size" heading.

## 5. Material descriptions

These blocks explain what each element does. Each appears on a piece only if that element is present. They are written to be reusable on product pages and, in expanded form, on the Atelier page. The Atelier page (document 06) develops them at greater length and does not copy them.

### 5.1 Vessel

**[WEBSITE COPY]** Block B-VESSEL

> The glass vessel sets the boundaries of the landscape. Its shape and proportions influence where hardscape is placed, how much room the plants have and the angles from which the composition is seen.

**Piece-specific line [TEMPLATE]:** This piece is built in {vessel_form}.

**Notes [INTERNAL]**

- Only describe vessel options that exist. Additional glass quality, sizes and shapes are future ambitions and must not be described as available. [REQUIRES CONFIRMATION]
- Do not describe the glass as "premium", "high quality" or "hand-blown" unless confirmed.

### 5.2 Substrate

**[WEBSITE COPY]** Block B-SUBSTRATE

> Substrate is the growing medium. It forms the base of the composition and holds the plants.

**Piece-specific line [TEMPLATE]:** The substrate in this piece uses {substrate_materials}.

**Optional role lines.** The brand documents list the substrate materials discussed (coco chips, peat moss, perlite and pumice) but do not state the role of each. The lines below are general horticultural descriptions. Publish them only if the business confirms they describe its own mix. [REQUIRES CONFIRMATION]

- Coco chips are a coarse, fibrous material made from coconut husk.
- Peat moss is a fine, moisture-holding organic material.
- Perlite is a light, white volcanic glass that opens up the mix.
- Pumice is a light volcanic rock that adds structure and air space.

**Notes [INTERNAL]**

- The exact mix and proportions vary by build. Do not present a universal substrate recipe. Do not give proportions.
- Name only the materials used in the piece, and only if the business wants substrate shown on that page.

### 5.3 Hardscape

**[WEBSITE COPY]** Block B-HARDSCAPE

> Hardscape refers to the natural structural elements, such as roots, wood and stone, that give the landscape its form. It introduces height, direction and variation.

**Material lines.** Publish only the lines for materials present in the piece.

- **Red Moor roots.** Natural root wood that introduces height and direction. [REQUIRES CONFIRMATION: description of the root form used]
- **Mangium wood.** Natural wood used for structure within the composition. [REQUIRES CONFIRMATION: the form in which it is used]
- **Stone.** Adds weight and texture to the arrangement.
- **Gravel.** Finishes the ground of the composition and can be varied in colour and size.

**Notes [INTERNAL]**

- **Wood naming.** The brand profile uses "Red Moor roots". The structure blueprint says "Red Moor wood". This document uses **Red Moor roots**. Keep it consistent in all files.
- **Not walnut.** The brand profile records a preference for mangium shelf wood rather than walnut. Never substitute walnut in copy or procurement assumptions.
- Do not describe the materials as rare, premium or sustainably sourced. Sourcing claims are unverified.

### 5.4 Moss

**[WEBSITE COPY]** Block B-MOSS

> Moss forms the softer surfaces of the landscape, adding texture and a ground-cover effect. Different mosses have different needs, so care guidance is specific to the piece.

**Piece-specific line [TEMPLATE]:** The moss in this piece is {moss_type}. (Only if the type is known.)

**Notes [INTERNAL]**

- Never imply that all mosses have identical care requirements.
- Do not name a moss species without confirmation.

### 5.5 Plants

**[WEBSITE COPY]** Block B-PLANTS

> Plants contribute form, foliage and growth. They are chosen for their shape and for how well they suit the composition and one another.

**Piece-specific line [TEMPLATE]:** This piece includes {plant_list}.

**Working plant list and accuracy notes [INTERNAL]**

The brand profile lists plants discussed for the business. It is a working list, not a stock list or a description of any piece. Each plant below may appear only when it is present in that piece and its identification is confirmed.

| Plant (as in the brand profile) | Accuracy note | Descriptive line, publishable only when confirmed |
|---|---|---|
| *Fittonia albivenis* | Botanical name is established | *Fittonia albivenis* has oval leaves marked with a network of fine veins. |
| "Raphidophora" | The genus is spelled **Rhaphidophora**. The brand profile spelling should be corrected before publication. A species is needed | None until the species is confirmed |
| *Hoya* | Genus only. A species is needed for a product page | *Hoya* is a genus of climbing and trailing plants, many with thick, waxy leaves. |
| Ferns | Species needed for each piece | Ferns contribute fronds, which contrast with the broader leaves of other plants. |
| Peacock ferns | "Peacock fern" is a common name that is used for more than one plant. A botanical name is needed. Confirm whether the plant is a true fern | None until identified |
| Needle grass | "Needle grass" is a common name that refers to different plants. A botanical name is needed | None until identified |
| Mosses | See block B-MOSS | See block B-MOSS |
| Other tropical and shade-adapted plants | Name each individually | None until identified |

**Notes [INTERNAL]**

- The descriptive lines are general botanical descriptions, not claims about any specific piece. The business should confirm the identification of each plant it uses. [REQUIRES CONFIRMATION]
- Do not describe plants as "rare", "exotic" or "hardy", and make no growth-rate or lifespan claims.

## 6. Description templates

### 6.1 Terrarium description [TEMPLATE]

Structure (2 to 4 sentences, using only confirmed data):

1. **The vessel.** {vessel_form} and, if relevant, how its shape suits the arrangement.
2. **The structure.** {hardscape_elements} and what they contribute.
3. **The planting.** {plant_list} and {moss_type}, with one observation about form or texture, if there is one.
4. **Optional.** A placement or care consideration specific to the piece.

Pattern:

> {Vessel_form} holds {hardscape_elements}, which give the arrangement its height and direction. {Plant_list} and {moss_type} fill the surfaces between them, with {one specific observation about leaf form, texture or layering}.

Rules:

- One specific observation at most. If none exists, omit it.
- Do not list every material in every description. Choose the details that explain this piece.
- Do not begin consecutive descriptions with the same word.

### 6.2 Kokedama description [TEMPLATE]

Structure (2 to 3 sentences, using only confirmed data):

1. **The plant.** {plant_name} presented through a moss-based planting technique.
2. **The form.** Size or variation, if confirmed.
3. **Optional.** One care consideration specific to this plant, taken from document 08.

Pattern:

> {Plant_name} presented through a moss-based planting technique. {Size or variation, if confirmed.}

Rules:

- No terrarium vocabulary.
- Do not describe construction, materials or display style beyond what the business confirms.
- The optional technique sentence in document 03 (section 03) applies only if confirmed.

### 6.3 Character line [TEMPLATE]

One sentence, 20 words or fewer, used in listings and on the homepage and collection pages.

Pattern:

> {Vessel_form} with {main hardscape element} and {main plant or moss}.

Rules:

- Name no more than two or three elements.
- No adjectives of praise.
- Must match the full description exactly in facts.

### 6.4 Image alt text [TEMPLATE]

Describe what is visible and nothing else.

- **Terrarium, full view:** {Piece name}: {format} terrarium with {principal elements}.
- **Close-up:** {Piece name}: close view of {element}.
- **Kokedama:** {Piece name}: kokedama with {plant_name}.

Do not use "beautiful", "stunning" or "perfect" in alt text. Do not name plants or materials that are not visible or confirmed.
